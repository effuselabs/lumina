# Onboarding Documentation

This directory contains essential onboarding materials for developers and AI assistants working on Lumina.

## Quick Navigation

- **[AI Context Guide](./AI_CONTEXT_GUIDE.md)** - Essential context for AI sessions
- **[Project Overview](./PROJECT_OVERVIEW.md)** - Current project state and goals
- **[Decision Log](./DECISION_LOG.md)** - Architectural decisions record

## Getting Started

### For AI Assistants
1. Start with the [AI Context Guide](./AI_CONTEXT_GUIDE.md) for essential context
2. Review the [Project Overview](./PROJECT_OVERVIEW.md) for current state
3. Check recent [Decision Log](./DECISION_LOG.md) entries for context

### For Developers
1. Review the [Project Overview](./PROJECT_OVERVIEW.md)
2. Check active features and current development status
3. Review recent architectural decisions in the [Decision Log](./DECISION_LOG.md)

## Maintenance

These documents should be updated regularly to maintain accuracy:
- AI Context Guide: Updated when essential documents change
- Project Overview: Updated weekly or when major features change status
- Decision Log: Updated immediately when architectural decisions are made
