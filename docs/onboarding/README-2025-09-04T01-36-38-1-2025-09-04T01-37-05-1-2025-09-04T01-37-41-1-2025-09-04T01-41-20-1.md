## 🏗️ Architecture

Each feature follows the Lumina architecture patterns:

- **Multi-tenant data isolation** - All features are business-scoped
- **NextAuth.js authentication** - Secure session management
- **Prisma ORM** - Type-safe database operations
- **React Server Components** - Modern React patterns
- **Tailwind CSS + shadcn/ui** - Consistent design system

## 📝 Documentation Standards

When adding new feature documentation:

1. Create a new directory under `/docs/features/[feature-name]/`
2. Include implementation details, API endpoints, and usage examples
3. Update this README with the new feature status
4. Link to related testing documentation
5. Follow the established documentation format
